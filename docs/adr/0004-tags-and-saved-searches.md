# Разделить тэги ресурсов и сохранённые поиски панели

Статус: принято, реализуется в текущей ветке.

Решено заменить единственную коллекцию ресурса множеством тэгов, а боковую панель строить из самостоятельных именованных сохранённых поисков. Поиск хранит набор обязательных тэгов, собственное имя и оформление. Дерево панели задаёт только визуальную организацию, поэтому перемещение узла не меняет ни тэги ресурсов, ни результаты других поисков. Такой выбор позволяет повторно использовать тэг в разных сочетаниях и не связывает модель ресурсов с расположением навигации. Согласованные правила поведения описаны в [проекте модели](../tag-model-design.md).
