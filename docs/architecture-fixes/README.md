## Независимость и интеграция

01 меняет только выполнение TextSnippet и добавляет отдельный порт записи clipboard, сохраняя существующий read-порт. 02 добавляет пакетную операцию и не меняет одиночное сохранение. 03 работает с существующими представлениями коллекций, не требует новой схемы. 04 полностью отвечает за миграцию membership и адаптацию всех затронутых сценариев. 05 сохраняет семантику ResourceDraft и выделяет получение метаданных путей.

Функциональных блокировок нет, но есть общие файлы: 02/03/04/05 затрагивают MainPage; 02/04 — persistence; 03/04 — операции коллекций. Поэтому независимость задач не означает отсутствие merge conflicts. Для одновременной реализации нужны отдельные ветки и адаптация к уже принятым контрактам при интеграции. 04 предпочтительно интегрировать после 02 и 03, чтобы один раз адаптировать новые операции к CollectionId; это рекомендация, а не обязательный blocker. При обратном порядке 02/03 используют уже принятый CollectionId.

Общие критерии: целевые tests проходят; изменения UI собираются и проверяются в работающем приложении; тесты persistence используют временную БД; пользовательские данные не используются для миграционных экспериментов. В обзоре успешный запуск тестов не подтверждён: VSTest сообщил таймаут подключения datacollector.
