# Реализованные пользовательские сценарии

Список относится к текущему исходному коду. Предварительный релиз v0.1.1 создан до перехода на тэги.

## Epic: Добавление ресурсов

- Пользователь создаёт ресурс вручную или с данными из буфера обмена.
- Пользователь выбирает тип, название, описание, адрес и визуал ресурса.
- Пользователь добавляет файл, папку, ссылку или подходящий текст перетаскиванием в окно.
- Пользователь создаёт ресурс из поиска: тэги поиска и временные тэги назначаются заранее.
- В поиске с условием «Корзина» создание недоступно.

## Epic: Просмотр и поиск

- Пользователь открывает обзор «Все ресурсы» без сохранённых условий; удалённые ресурсы скрыты.
- Пользователь выбирает один именованный поиск в боковой панели.
- Обязательные тэги поиска и временные тэги соединяются условием «И».
- Текст ищется по названию, описанию, адресу и типу, без сопоставления имён тэгов.
- При переходе к другому поиску текст и временные тэги очищаются.
- Пользователь сортирует результаты по названию или дате изменения и переключает сетку и список.

## Epic: Тэги и сохранённые поиски

- Пользователь назначает ресурсу несколько тэгов; поле ввода предлагает существующие имена и создаёт новый тэг по Enter.
- Пользователь вручную назначает и снимает «Входящие»; «Корзина» меняется только удалением и восстановлением.
- Пользователь создаёт именованный поиск кнопкой «Сохранить поиск» рядом с полем поиска; сохраняются только тэги.
- Пользователь редактирует имя, условия, иконку, цвет и родителя поиска; одинаковые имена разных поисков допустимы.
- Пользователь переставляет поиски, вкладывает их для отображения и удаляет поддерево после подтверждения.
- Перетаскивание ресурса на поиск назначает недостающие обязательные тэги после подтверждения.
- Пользователь переименовывает тэг без потери его связей; удаление тэга, используемого поисками, запрещено.

## Epic: Действия с ресурсами

- Пользователь открывает ресурс двойным щелчком, клавишей Enter или через контекстное меню.
- Пользователь копирует текст заметки в буфер обмена, открывая её.
- Пользователь редактирует ресурс и выбирает автоматический визуал, своё изображение или значок типа.
- Пользователь удаляет ресурс в корзину, сохраняя остальные тэги.
- Пользователь восстанавливает ресурс; при отсутствии пользовательских тэгов ресурс получает «Входящие».
- Пользователь окончательно удаляет ресурс из корзины или очищает её после подтверждения.

## Epic: Сохранение рабочего пространства

- Пользователь продолжает работу с ресурсами, тэгами и сохранёнными поисками после перезапуска.
- Представление и сортировка сохраняются между запусками.
- Рабочее пространство хранится в `content` рядом с приложением или в выбранном пользователем каталоге.
- Перед созданием пустой базы новой схемы старая база коллекций сохраняется как резервная копия.
