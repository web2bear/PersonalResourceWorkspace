# Реализованные пользовательские сценарии

Короткие заголовки User Stories, сгруппированные по эпикам. Список описывает возможности текущей реализации; планы из [спецификации](../PROJECT.md) сюда не включены.

## Epic: Добавление ресурсов

- Пользователь создаёт ресурс вручную через кнопку «Добавить».
- Пользователь создаёт веб-ссылку через кнопку «Добавить», указав её адрес в редакторе.
- Пользователь создаёт ресурс через кнопку «Добавить» с данными, подставленными из буфера обмена.
- Пользователь создаёт веб-ссылку перетаскиванием в окно приложения.
- Пользователь создаёт ресурс из файла или папки перетаскиванием в окно приложения.
- Пользователь создаёт ресурс из перетащенного текста, содержащего ссылку или путь.
- Пользователь выбирает при ручном добавлении тип ресурса: приложение, веб-ссылка, файл, папка, заметка, изображение или команда.

## Epic: Просмотр и поиск

- Пользователь просматривает все ресурсы, кроме помещённых в корзину.
- Пользователь просматривает ресурсы выбранной коллекции.
- Пользователь просматривает избранные ресурсы.
- Пользователь ищет ресурсы по названию, описанию, адресу или типу в текущем разделе.
- Пользователь сортирует ресурсы по названию или дате изменения.
- Пользователь переключает представление ресурсов между сеткой и списком.
- Пользователь видит число ресурсов в разделе и рядом с коллекциями.

## Epic: Действия с ресурсами

- Пользователь открывает ресурс двойным щелчком, клавишей Enter или через контекстное меню.
- Пользователь копирует текст заметки в буфер обмена, открывая её.
- Пользователь редактирует название, описание, тип и адрес ресурса.
- Пользователь переносит ресурс в другую коллекцию через редактор.
- Пользователь добавляет ресурс в избранное или убирает его оттуда через редактор.
- Пользователь выбирает для карточки автоматический визуал, собственное изображение или значок типа.
- Пользователь удаляет ресурс в корзину после подтверждения.

## Epic: Коллекции

- Пользователь создаёт коллекцию с названием, цветом и значком либо изображением.
- Пользователь переходит между коллекциями через боковую панель.
- Пользователь переименовывает коллекцию.
- Пользователь меняет значок, цвет или изображение коллекции.
- Пользователь удаляет коллекцию после подтверждения, перенося её ресурсы в другую коллекцию.

## Epic: Корзина

- Пользователь просматривает ресурсы в корзине.
- Пользователь удаляет отдельный ресурс из корзины безвозвратно после подтверждения.
- Пользователь очищает корзину после подтверждения.

## Epic: Сохранение рабочего пространства

- Пользователь продолжает работу с сохранёнными ресурсами и коллекциями после перезапуска приложения.
- Пользователь продолжает работу в выбранном представлении коллекции после перезапуска приложения.
