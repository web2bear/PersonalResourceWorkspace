# Personal Resource Workspace

Рабочее пространство ресурсов, которые пользователь описывает тэгами и находит через закреплённую навигацию. Ниже зафиксирован язык модели приложения.

## Язык

**Ресурс**:
Сохранённый объект рабочего пространства, например ссылка, файл или заметка.

**Тэг**:
Именованная характеристика ресурса. Один ресурс может иметь несколько тэгов; в первой версии тэг не имеет визуальных атрибутов.
_Избегать_: коллекция, когда имеется в виду характеристика ресурса.

**Предопределённый тэг**:
Тэг «Корзина» или «Входящие», который существует в рабочем пространстве и не может быть удалён пользователем.

**Входящие**:
Предопределённый тэг для ресурса без пользовательских тэгов при создании. При назначении первого пользовательского тэга снимается автоматически, но может быть назначен вручную.

**Корзина**:
Предопределённый тэг для удалённого ресурса. Остальные тэги ресурса сохраняются до восстановления или окончательного удаления.

**Сохранённый поиск**:
Именованный набор обязательных тэгов для поиска ресурсов, представленный узлом боковой панели со своим цветом и иконкой. Узлы организованы в дерево только для отображения; их расположение не влияет на результаты поиска и связи ресурсов с тэгами.
_Избегать_: коллекция, закреплённый тэг, когда имеется в виду узел навигации.

**Обзор «Все ресурсы»**:
Доступный без сохранения поиск без обязательных тэгов, показывающий ресурсы вне Корзины.
